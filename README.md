# Blog Customizer

Интерактивное React-приложение для настройки внешнего вида статьи в реальном времени. Пользователь может изменять шрифт, размер текста, ширину контента и цветовую схему через боковую панель настроек.

# Репозиторий

- https://github.com/DefteEspero/blog-customizer

## Функциональность

- Открытие и закрытие панели настроек
- Закрытие панели по клику вне области формы
- Изменение параметров статьи через форму
- Применение настроек только после нажатия кнопки «Применить»
- Сброс параметров к значениям по умолчанию
- Использование CSS-переменных для изменения стилей
- Адаптивная верстка

## Установка и запуск

### Клонирование репозитория

```bash
git clone <ссылка-на-репозиторий>
cd blog-customizer-main
```

### Установка зависимостей

```bash
npm install
```

### Запуск проекта

```bash
npm start
```

После запуска проект будет доступен по адресу:

```bash
http://localhost:8080
```

## Дополнительные команды
